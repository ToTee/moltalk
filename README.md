# 몰톡

디시인사이드를 메신저 화면으로 보는 **비공식** 앱입니다. 갤러리는 친구, 글은 채팅방, 댓글은 대화로 보입니다.
디시인사이드와 관계없는 개인 프로젝트이며, 내려받기는 [Releases](../../releases)에서 할 수 있습니다.

- 윈도우: `MolTalk-Setup-<버전>.exe` (실행하면 설치되고 바탕 화면에 바로 가기가 생깁니다)
- 안드로이드: `MolTalk-<버전>.apk` (안드로이드 7.0 이상)

## 기능

- 갤러리 검색·추가·즐겨찾기, 글 목록(말머리, 공지 고정·접기), 본문과 댓글 보기
- 갤러리 이름을 사람 이름으로 바꿔 보기
- 로그인 후 글쓰기, 댓글, 디시콘·더블콘·글자콘, 글 수정·삭제, 댓글 삭제
- 갤로그(게시글·댓글·스크랩·방명록), 내 글과 댓글의 새 댓글 알림(10분마다 확인)

## 알아 둘 점

- 로그인은 앱 안에서 열리는 디시인사이드 공식 로그인 화면에 직접 합니다. 앱은 비밀번호를 저장하거나 다른 곳으로 보내지 않습니다.
- 앱은 디시인사이드 주소로만 요청합니다. 요청이 너무 잦으면 디시인사이드가 잠시 접속을 막을 수 있어, 미리보기는 하나씩 간격을 두고 불러옵니다.
- 실행 파일에는 유료 코드 서명이 없어 윈도우와 안드로이드가 설치할 때 경고를 보여 줄 수 있습니다.

## 직접 빌드하기

Node.js 20 이상이 필요합니다.

```
npm install
npm start          # 윈도우에서 바로 실행
npm run build:exe  # release/ 에 설치 파일(EXE) 생성
npm run build:apk  # android/out/ 에 APK 생성
```

APK 빌드는 그래들 없이 진행하며, 아래 도구를 `android-tools/` 에 풀어 두어야 합니다.

- `android-tools/build/android-15` : 안드로이드 빌드 도구 35
- `android-tools/platform/android-35` : 안드로이드 플랫폼 35
- `android-tools/jdk/jdk-17*` : JDK 17

서명 키는 저장소에 없습니다. 없으면 빌드할 때 그 PC 전용 키를 새로 만들며, 다른 키로 서명한 APK로는 덮어쓰기 설치가 되지 않습니다.

## 구조

- `src/core/dc.js` : 디시인사이드 읽기(검색, 목록, 본문, 댓글)
- `src/core/drive.js` : 공식 모바일 화면을 통한 로그인·쓰기·삭제·갤로그
- `src/ui/` : 화면
- `desktop/` : 윈도우 껍데기(Electron)
- `android/` : 안드로이드 껍데기(WebView)
